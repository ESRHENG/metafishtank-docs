**The Infrastructure for User-Generated Agents (UGA) on BNB Chain**

> **Draw Locally, Evolve Globally.**

MetaFishtank turns user creativity into persistent, programmable, AI-native game assets. Users create the Agent. **Anima Engine™** interprets it. **MAP** gives it portable state. Games become interchangeable environments in which the same Agent can evolve.

A drawing is not treated as a finished image. It becomes the origin of an Agent lifecycle:

**Expression → Interpretation → Incarnation → Interaction → Evolution**

MetaFishtank follows an **Asset-First** architecture: the Agent is the persistent constant while games become replaceable environments.

The stack is organized into three functional layers:

1. **MAP — Protocol Layer** — portable identity, state, permissions and cross-game evolution.
2. **Anima Engine™ — Intelligence Layer** — interpretation, validation, trait compilation, behavior and developer runtime.
3. **Tank Ecosystem — Application Layer** — official and third-party games where Agents are created, used, socialized and evolved.

MetaFishtank is **not a new blockchain, rollup, or Layer 2**. The initial on-chain deployment is built on **BNB Smart Chain (BSC)**.

> **BNB Chain provides the execution environment. MAP defines the asset language. Anima gives the asset life.**
