# 🧬 2. The Era of Living Assets

## 2.1 From UGC to UGA

User-Generated Content (UGC) transformed digital platforms by allowing users to create media, maps, skins, worlds and experiences. In blockchain gaming, however, most UGC remains passive. A user may own the content, but the asset does not independently maintain behavior, memory or an evolving identity.

A **User-Generated Agent** extends UGC with persistent machine-readable state.

Each MetaFishtank Agent is conceptually composed of five dimensions:

1. **Visual Identity** — the original user expression and its canonical representation.
2. **DNA** — immutable creation-time traits and provenance.
3. **State** — mutable attributes such as level, experience, skills, status and game-derived variables.
4. **Behavior Profile** — machine-readable parameters that guide how the Agent behaves inside compatible environments.
5. **Memory & Evolution** — verifiable summaries of important interactions and changes over time.

Not every part of an Agent must live fully on-chain. MetaFishtank deliberately separates **ownership-critical state** from **compute-heavy intelligence** so the system can remain usable, affordable and composable.

## 2.2 Persistence Without Game Lock-In

MAP decouples an Agent from any one application.

A racing game may interpret an Agent's `speed` and `agility` traits. A battle game may consume `attack`, `defense` and learned skills. A social simulation may read personality or memory references. The same underlying Agent remains identifiable across each experience.

This does not mean every game must interpret every trait identically. MAP provides a **shared semantic layer plus game adapters**, allowing developers to map canonical Agent attributes into genre-specific mechanics while preserving provenance and ownership.

## 2.3 The Living Asset Thesis

A Living Asset differs from a normal NFT in three important ways:

- **It can change without losing identity.** Ownership remains stable while approved state evolves.
- **Its utility can expand with new environments.** A new game can create new use cases without reissuing the asset.
- **Its history becomes part of its value.** Skills, achievements, relationships, game participation and reputation can remain attached to the same persistent Agent identity.

MetaFishtank therefore treats the asset as a long-lived digital entity rather than a collectible that depends on one application's lifespan.

## 2.4 From Ownership to Stewardship

The user's relationship with a MetaFishtank Agent is designed to feel closer to **stewardship** than inventory management.

Users do not merely hold a token. They create, nurture, train, expose, upgrade, socialize, compete with and carry an Agent across experiences. This emotional and behavioral loop is essential: infrastructure becomes valuable when users care about the state being preserved.
