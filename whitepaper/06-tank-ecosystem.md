# 6. Tank Ecosystem & Open Ocean

The Tank Ecosystem is the application and distribution layer in which persistent Agents become useful.

## 6.1 Official Reference Applications

MetaFishtank uses focused reference applications to prove specific parts of the protocol rather than committing to an unrealistic catalogue of first-party games.

**Upcoming first-party games:** Aqua Arena (combat arena) and Predator Protocol (big-fish-eat-small-fish real-time survival) are first-party games planned for subsequent launch. Once live, they will follow the same platform rules as third-party games: one unified platform identity, one daily-task allowance per identity per day, and at least one $MFT spending option per game. Abyss Horizon remains a long-term research direction, not a near-term launch commitment.

### Drawafish — Creation Proof

Demonstrates:

- user-generated Agent creation;
- Anima interpretation;
- minting and ownership;
- social discovery;
- nurturing and progression;
- the first population of persistent Agents.

### Aqua Arena — Trait & Battle Proof

Demonstrates:

- canonical combat traits;
- matchmaking;
- bounded progression;
- achievement write-back;
- seasonal competition.

### Predator Protocol — Real-Time State Proof

A fast survival / “big fish eat small fish” reference experience designed to demonstrate:

- rapid Agent interactions;
- game-local state;
- event indexing;
- bounded canonical progression;
- repeatable cross-session state updates.

### Abyss Horizon — High-Fidelity Vision

A long-term reference direction for demonstrating how the same persistent Agent identity could be rendered in a higher-fidelity world.

It is a vision and research target, not a launch dependency.

## 6.2 Third-Party Game Integration

Third-party games can integrate at different depths.

### Level 1 — Read-Only

Authenticate ownership and read Agent traits. No persistent write-back.

### Level 2 — Progression

Receive an approved namespace and write bounded achievements, XP or progression.

### Level 3 — Deep Agent Integration

Use Anima runtime services, structured memory, advanced behavior or canonical trait proposals under stronger validation and review.

## 6.3 Open Ocean: The Long-Term Distribution Vision

The long-term goal is **Open Ocean**: an open distribution and interoperability network for User-Generated Agents.

The simplest shorthand is the **“Steam of UGA” vision**, but the architecture goes beyond a conventional game store.

Traditional distribution platforms primarily connect games with players. Open Ocean is designed to connect:

- **Players** with experiences where their existing Agents already have utility;
- **Developers** with a ready-made inventory of user-owned Agents;
- **Agents** with new environments where they can evolve;
- **AI services** with applications that require creation, behavior, memory or verification;
- **economic incentives** with measurable contribution to persistent Agent value.

A studio integrating MAP should be able to inherit part of an existing Agent and user economy rather than starting from zero.

> **Users create the Agents. Developers create the worlds. The protocol lets value flow between them.**
