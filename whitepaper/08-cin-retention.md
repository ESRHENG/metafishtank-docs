# 💞 8. The C.I.N. Retention Model

Drawafish is designed around three mutually reinforcing psychological loops:

**Creativity × Interactivity × Nurturing**

## 8.1 C — Creativity: Visual Sovereignty

Users begin by making something rather than buying something.

- **Low Barrier:** Almost anyone can create a recognizable Fish.
- **High Ceiling:** Skilled users can create visually distinctive Agents.
- **Identity:** The visual origin of an Agent becomes personal rather than factory-issued.
- **Endowment Effect:** Creation can increase emotional attachment compared with simply purchasing a pre-made asset.

The system should reward original expression without pretending that visual appearance is a scientifically deterministic predictor of combat power.

## 8.2 I — Interactivity: The Tank as Social Graph

Agents gain relevance when other people can discover, react to and interact with them.

Interactivity can include:

- visiting Tanks;
- feeding or helping neighbors;
- aesthetic discovery;
- social voting;
- Guild activities;
- Arena competition;
- creator challenges;
- cross-game achievements.

The Tank becomes a visual social graph rather than a static wallet gallery.

## 8.3 N — Nurturing: Visible Growth

Users should be able to see the difference between an Agent they created yesterday and one they have developed for months.

Nurturing can produce:

- visual evolution;
- level progression;
- skill unlocks;
- relationship state;
- squad formation;
- cross-game badges;
- persistent memories;
- reputation and creator status.

The satisfaction comes from moving from:

**One simple Fish → A developed Agent → A coordinated Squad → A persistent cross-game identity.**

The C.I.N. model matters because protocol interoperability alone does not create retention. Users must care about the identity being preserved.
