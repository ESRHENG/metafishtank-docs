# 12. Roadmap

The roadmap is designed around proof of persistent Agent utility rather than the number of games launched.

## Phase A — BNB Foundation

- deploy and test EVM-native MAP contracts;
- BSC wallet integration;
- minting flow;
- indexer and state services;
- Solidity unit / invariant / fuzz testing;
- storage and gas profiling;
- contract verification;
- eligible legacy provenance snapshot-and-claim flow where required.

## Phase B — Test Seasons T1–T3 (Public Beta Season 2)

- launch BNB edition of Drawafish;
- three test seasons, each with 42 days of play plus 7 days of review;
- FP-only participation, with no token rewards during testing;
- test creation and Agent persistence;
- measure retention, uniqueness and social interaction;
- game-airdrop eligibility (10 million $MFT budget) with independent identity review;
- anti-bot / anti-Sybil calibration;
- indexer stress testing, gameplay and SDK feedback;
- re-run and calibrate the economic model with real test-season data, and publish that data.

## Phase C — TGE and Official Season S1

- $MFT launch and official liquidity pool;
- third-party audit of core contracts completed and report published;
- production MAP deployment and finalized creation / minting flow;
- official fish raising (game mining) and staking;
- public on-chain dashboard;
- contract and security documentation;
- marketplace features only when security and product readiness justify them.

## Phase D — Reference Game Expansion

- Aqua Arena;
- Predator Protocol prototype;
- deeper Agent progression;
- ECS developer attribution testing;
- cross-game achievement write-back;
- richer Agent memory.

## Phase E — Open Ocean SDK

- TypeScript SDK;
- Unity toolkit;
- Unreal toolkit;
- public adapter documentation;
- developer sandbox;
- game namespace tools;
- attribution dashboard.

## Phase F — Agent Economy Compatibility

- ERC-8004 adapters where useful;
- evaluate emerging BAP-578 compatibility;
- BNB Agent SDK integration where useful;
- Agent commerce and payment experiments;
- portable reputation and validation modules.

## Phase G — Scale

- larger third-party game network;
- Open Ocean discovery and distribution;
- optional opBNB execution modules where justified;
- expanded state indexers and data services;
- advanced Anima Developer Runtime;
- high-fidelity Agent representation research, including the long-term Abyss Horizon vision.

The roadmap is directional. Specific dates and launch conditions should be published separately as engineering, security and ecosystem dependencies become measurable.
